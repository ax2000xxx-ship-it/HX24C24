# مشروع HX - منصة تحميل ملفات وألعاب

موقع خفيف، سريع ومتجاوب بالكامل باللغة العربية، مصمم ليعمل بدون خادم خلفي (Serverless) ويمكن رفعه مجاناً على **GitHub Pages**.

## 🚀 المميزات:
- **نظام بحث فوري**: يدعم العربية والإنجليزية (غير حساس لحالة الأحرف).
- **أقسام وتصنيفات ديناميكية**: تتولد تلقائياً بناءً على محتوى الملفات.
- **لوحة تحكم إدارة متكاملة**:
  - تفتح عند كتابة رمز الإدارة السري في مربع البحث (الرمز الافتراضي: `HX2423DEV`).
  - إمكانية إضافة، تعديل، وحذف المنشورات بسهولة.
  - إمكانية تغيير رمز الدخول السري للوحة وحفظه في المتصفح.
  - ضغط الصور تلقائياً محلياً باستخدام Canvas.
  - زر تصدير `items.json` جاهز للرفع على GitHub.
- **دعم الوضع الداكن / الفاتح**: وحفظ التفضيل في المتصفح.
- **تأثيرات بصرية وتحميل سلس**.

## 📁 هيكل المشروع:
- `index.html`: الصفحة الرئيسية للموقع مع كافة الأنماط والوظائف.
- `items.json`: قاعدة البيانات للملفات والألعاب المعروضة.

## 🌐 النشر على GitHub Pages:
1. أنشئ مستودعاً جديداً (New Repository) على GitHub باسم `hx` أو أي اسم تختاره.
2. ارفع ملفات المشروع (`index.html` و `items.json`).
3. توجه إلى **Settings** > **Pages** واجعل الـ Source من فرع `main` أو `master`.
4. سيصبح موقعك متاحاً للجميع مجاناً!
